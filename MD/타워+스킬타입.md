# 타워 + 스킬 타입 구조 문서

> Project_RTD — Phaser 3 기반 타워 디펜스 게임  
> 최종 업데이트: 2026-06-26

---

## 1. 전체 아키텍처 개요

```
stats.json (데이터)
    ├── units[]        ← 타워 유닛 정의 (능력치 + skillId 참조)
    └── skills{}       ← 스킬 정의 (발사체 동작 + category)

Tower.js (런타임)
    ├── unitData       ← stats.json units 항목
    ├── skills[]       ← SkillFactory.create(skillId) → 스킬 인스턴스
    └── update()       ← attackTimer 누적 → attack() → skill.execute()

SkillClasses.js (스킬 실행)
    └── execute(tower, target)
            └── ProjectilePool.acquire(…, skillData)

Projectile.js (투사체)
    └── hit 처리
            ├── CombatSystem.calculateDamage()   ← 일반 데미지
            └── monster.applyPoison()             ← duration 스킬만

Monster.js (피격 대상)
    ├── takeDamage(amount)   ← 즉시 피해
    ├── applyPoison(…)       ← 독 중첩 등록
    └── _updatePoison(delta) ← 매 프레임 틱 처리
```

## 2. 타워 유닛 데이터 스키마 (`stats.json` → `units[]`)

### 2-1. 공통 필드 (모든 유닛)

| 필드 | 타입 | 설명 | 예시 |
|---|---|---|---|
| `id` | string | 유닛 고유 키 (코드에서 참조) | `"n1"`, `"r2_yeon"` |
| `name` | string | 표시 이름 | `"병사"` |
| `tier` | string | 뽑기 등급 (9단계) | `"normal"` |
| `attackType` | string | 공격 속성 (3종) | `"normal"` |
| `damage` | number | 기본 공격력 | `95` |
| `attackSpeed` | number | 공격 쿨다운 (ms) — 낮을수록 빠름 | `1000` |
| `range` | number | 사거리 (픽셀) | `120` |
| `skillId` | number | 사용할 스킬 ID (→ skills 참조) | `1` |
| `gradeScore` | number | 등급 점수 (시뮬레이션 평가용) | `100` |
| `gachaAvailable` | boolean | 뽑기 풀 포함 여부 | `true` |
| `criticalRate` | number | 치명타 확률 (1/10000 단위) — `500` = 5% | `500` |

### 2-2. 지속 피해 전용 필드 (duration 스킬 유닛만)

> `skillId`가 `category: "duration"` 스킬을 가리킬 때만 의미 있음

| 필드 | 타입 | 설명 | 기본값 |
|---|---|---|---|
| `poisonDuration` | number | 독 효과 지속 시간 (ms) | — |
| `maxPoisonStacks` | number | 독 최대 중첩 횟수 | `10` |
| `tickRate` | number | 피해 적용 주기 (ms) | `1000` |
| `poisonDamageRatio` | number | 1틱 피해 = `damage × ratio × stacks` | `0.2` |

### 5-1. 스킬 공통 필드

| 필드 | 타입 | 설명 |
|---|---|---|
| `id` | number | 스킬 고유 ID |
| `name` | string | 표시 이름 |
| `nameEn` | string | 코드 식별자 (라우팅 키) |
| `category` | string | 스킬 분류: `"instant"` 또는 `"duration"` |

| `projectileSpeed` | number | 투사체 이동 속도 (`0` = Hitscan) |
| `displaySize` | number | 투사체 표시 크기 (px) |
| `fallbackShape` | string | 이미지 없을 때 대체 도형 |
| `imagePath` | string | 투사체 이미지 경로 |

### 5-2. 현재 정의된 스킬 목록

| ID | 이름 | `nameEn` | `category` | 속도 | 특징 |
|---|---|---|---|---|---|
| 1 | 느린 사격 | `BASE_SHOT` | `instant` | 3 | 느린 원형 투사체 |
| 2 | 일반 사격 | `BASE_SHOT` | `instant` | 5 | 표준 투사체 |
| 3 | 빠른 사격 | `BASE_SHOT` | `instant` | 7 | 빠른 다이아몬드 투사체 |
| 4 | 연쇄 번개 | `CHAIN_ATTACK` | `instant` | 4 | 적 사이 최대 5회 연쇄 타격 |
| 5 | 맹독 중첩 | `POISON_DOT` | `duration` | 7 | 투사체 적중 → 독 중첩 |

### 5-3. category별 동작 차이

| 구분 | `instant` | `duration` |
|---|---|---|
| **치명타 판정** | 발동 가능 (`criticalRate` 적용) | 항상 0% (치명타 없음) |
| **독 중첩 적용** | 없음 | `monster.applyPoison()` 호출 |
| **투사체 클래스** | `SingleShotSkill` / `ChainLightningSkill` | `PoisonDotSkill` |
| **에디터 활성 컬럼** | 연쇄 관련 필드 | 지속시간·중첩 필드 |

### 5-4. 연쇄 번개 전용 추가 필드 (`CHAIN_ATTACK`)

| 필드 | 설명 | 기본값 |
|---|---|---|
| `bounceCount` | 최대 연쇄 횟수 | `5` |
| `bounceRange` | 연쇄 탐색 반경 (px, `0` = 무제한) | `0` |
| `bounceDamageMultiplier` | 연쇄마다 데미지 감쇠 비율 | `0.85` |
| `fallbackColor` | 번개 투사체 색상 | `0x00CCFF` |

### 5-5. 독 (POISON_DOT) 전용 추가 필드

> `skillData`에 정의. `unitData`에 없어도 스킬 데이터에서 읽음.

| 필드 | 설명 | 현재값 |
|---|---|---|
| `poisonDuration` | 독 지속 시간 (ms) | `5000` |
| `maxPoisonStacks` | 최대 중첩 | `10` |
| `tickRate` | 피해 적용 주기 (ms) | `1000` |
| `poisonDamageRatio` | 1틱 피해 비율 | `0.2` |

## 6. 스킬 라우팅 — `SkillFactory.create(skillId)`

```
skillId → skillData 로드 → nameEn 기반 switch
  ├── 'CHAIN_ATTACK'  → ChainLightningSkill
  ├── 'POISON_DOT'    → PoisonDotSkill
  └── 기타 / 'BASE_SHOT' → SingleShotSkill
```

**추후 새 스킬 추가 시 자동 적용되는 것:**
- `category: "duration"` → 치명타 0% 자동 (CombatSystem)
- `category: "duration"` → `applyPoison()` 자동 호출 (Projectile)
- 전용 클래스 없으면 `SingleShotSkill`로 폴백 동작

## 7. 데미지 계산 공식

```
1. 타입 상성
   effectiveness = TYPE_EFFECTIVENESS[attackType][monsterType]

2. 치명타 판정 (instant 스킬만)
   if (skillData.category !== 'duration'):
     isCritical = (random() × 10000 < criticalRate)

3. 최종 데미지
   finalDamage = floor(damage × effectiveness)
   if isCritical:
     finalDamage = floor(finalDamage × (1 + CRITICAL_DAMAGE_RATIO))
     → CRITICAL_DAMAGE_RATIO = 0.5  →  최종 ×1.5배
```

**치명타 설정값:**
- `criticalRate: 500` = 5%, `1000` = 10%, `10000` = 100%, `0` = 치명타 없음

## 8. 독(DoT) 시스템 — 데이터 흐름

```
[투사체 적중]
  this.skill.category === 'duration'
      ↓
  monster.applyPoison(towerId, unitData, skillData)
      ↓
  monster.poisons[towerId] = {
      stacks: 1 ~ maxStacks,
      remaining: poisonDuration,
      tickAccum: 0,
      baseDamage: unitData.damage,
      tickRate, maxStacks, duration, ratio
  }

[매 프레임 update()]
  _updatePoison(delta)
      for each tower's poison:
        remaining -= delta
        tickAccum += delta
        while (tickAccum >= tickRate):
          hp -= floor(baseDamage × ratio) × stacks
          tickAccum -= tickRate
        if remaining <= 0: 독 해제
      if 모든 독 해제: 오버레이 제거
```

**독 시각 효과:**
- 독 적중: 몸체 뒤 **초록 원형 글로우** (poisonOverlay Graphics)
- 펄스: `alpha = 0.3 + sin(time/300) × 0.15` 반복
- 예측 체력바: 현재 HP 바에서 좌측 방향 **보라색 게이지**

## 10. 타워 공격 루프

```javascript
// Tower.update(time, delta, monsters)
attackTimer += delta
if attackTimer >= unitData.attackSpeed:
  target = CombatSystem.findTarget(tower, monsters)
  // 배속 모드에서 누적 타이머로 복수 공격 지원 (최대 5발/프레임)
  while (attackTimer >= atkSpeed && count < 5):
    skill.execute(tower, target, monsters)
    attackTimer -= atkSpeed
```

## 11. 타워 시각 외형 규칙

| 조건 | 외형 |
|---|---|
| `attackType === 'vibration'` | 원형 스피커 (초록 코어) |
| `attackType === 'explosive'` | 삼각형 포탑 (빨간 코어) |
| `skillId === 4` (연쇄 번개) | 다이아몬드 + 청록 번개 Z자 코어 |
| 그 외 (normal) | 별(★) 형태 (공격타입 색상 코어) |

> 몸체 색상 = 등급 색상 (`COLORS.TIER`), 코어 색상 = 공격 타입 색상 (`COLORS.ATTACK_TYPE`)
